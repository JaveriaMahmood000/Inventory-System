# 📦 Inventory Management System (Python)

## About This Project
This is a simple Inventory Management System that I built using Python while learning Object-Oriented Programming. The main idea was to understand how basic inventory systems work in real life, like how products are added, updated, and managed in a store.

The project runs in the console and stores data in a JSON file so that the information stays savedaa even after closing the program.


## What it can do

- Add new products (ID, name, price, quantity)
- Show all products in the inventory
- Search a product by ID
- Update product price or quantity
- Delete products from the system
- Show low stock items (less than 5 quantity)
- Calculate total value of all inventory
- Save data permanently using JSON


## Tools I Used

- Python  
- OOP (Object-Oriented Programming)  
- JSON file handling  
- Basic OS module
